# Rein

Rein is a strict, TypeScript-like language for AI agent decision processes. A process asks the agent typed questions, and plain `if` and `switch` code picks the next step. The agent follows the process instead of guessing. Read more at [rein-lang.com](https://rein-lang.com).

Start with [Getting started](https://rein-lang.com/docs/getting-started). Read the full [docs](https://rein-lang.com/docs/).

## Programs

Install a program with `rein install -g github:rein-lang/<name>`.

- [logo-creation](https://github.com/rein-lang/logo-creation): create a logo for a project. A brief, three SVG concepts, and the user's pick.
- [vscode-extension](https://github.com/rein-lang/vscode-extension): ship a VS Code extension to the Marketplace. A name, a publisher, an icon, publishing from git tags, and an install check.

## Tools

- [vscode-rein](https://github.com/rein-lang/vscode-rein): Rein support for VS Code. Install [Rein Language](https://marketplace.visualstudio.com/items?itemName=rein-lang.rein-language) from the Marketplace.
- [rein-lang.com](https://github.com/rein-lang/rein-lang.com): the website and the docs.
